Alapvető vezérlési szerkezetek

Ismerd meg a feltételes elágazásokat és a ciklusok működését C# nyelven.

1. Elágazás – if, else

Feltétel alapján különböző utasításokat hajt végre.

if (a > b)
{
    Console.WriteLine("A nagyobb");
}
else
{
    Console.WriteLine("B nagyobb vagy egyenlő");
}

2. Többágú elágazás – switch

Egy változó értéke alapján választ a lehetőségek közül.

switch (nap)
{
    case 1:
        Console.WriteLine("Hétfő");
        break;
    case 2:
        Console.WriteLine("Kedd");
        break;
    default:
        Console.WriteLine("Másik nap");
        break;
}

3. Ciklusok – for, foreach, while

for: ismert ismétlésszám esetén használható.

for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

foreach: egy tömb vagy kollekció elemein halad végig.

int[] szamok = { 1, 2, 3 };

foreach (int szam in szamok)
{
    Console.WriteLine(szam);
}

while: addig ismétli az utasításokat, amíg a feltétel igaz.

int i = 0;

while (i < 5)
{
    Console.WriteLine(i);
    i++;
}

Lényeg: az if és switch elágazásokat, a for, foreach és while ismétléseket valósít meg.

Inicializálás, konstruktorok és property-k

Ismerd meg a változók és objektumok inicializálását, a konstruktorokat és a property-k használatát.

1. Inicializálás

Az inicializálás során kezdőértéket adunk a változóknak, mezőknek vagy objektumoknak. 

class Alakzat
{
    private double a = 10;
    private double b;

    public static int darab = 0;
}

2. Statikus inicializálás – static

  • static: az osztályhoz tartozik, nem egy konkrét objektumhoz.
  • A statikus mezőből közös adatot tárolhatunk minden objektum számára.
  • A statikus konstruktor egyszer fut le, az osztály első használatakor.
class Alakzat
{
    public static int darab;

    static Alakzat()
    {
        darab = 0;
    }
}

3. Konstruktor

A konstruktor objektum létrehozásakor automatikusan lefut. Neve megegyezik az osztály nevével, és általában az adatok kezdőértékének beállítására szolgál. 

class Teglalap
{
    private double a;
    private double b;

    public Teglalap(double a, double b)
    {
        this.a = a;
        this.b = b;
    }
}

Teglalap t = new Teglalap(10, 5);

4. Property – tulajdonság

A property szabályozott hozzáférést biztosít az osztály mezőihez.

  • get: a mező értékének lekérése.
  • set: a mező értékének módosítása.
  • private set: kívülről nem módosítható.
class Teglalap
{
    public double A { get; set; }

    public double B { get; private set; }

    public Teglalap(double a, double b)
    {
        A = a;
        B = b;
    }
}

5. Automatikus property

Az automatikus property esetén a C# automatikusan létrehozza a háttérben tárolt mezőt. 

public string Nev { get; set; }

public double Terulet { get; private set; }

Lényeg: az inicializálás kezdőértéket ad, a konstruktor létrehozáskor beállítja az objektum adatait, a static az osztályhoz tartozik, a property pedig szabályozza az adatok elérését és módosítását.

Kollekciók – List, Dictionary, HashSet

Ismerd meg a C# leggyakrabban használt adatszerkezeteit és azok működését.

1. List – lista

A List dinamikus méretű lista, amelyben több azonos típusú elemet tárolhatunk. Az elemek index alapján érhetők el. 

List<string> nevek = new List<string>();

nevek.Add("Anna");
nevek.Add("Béla");

Console.WriteLine(nevek[0]);

nevek.Remove("Béla");

2. Dictionary – szótár

A Dictionary kulcs-érték párokat tárol. Az értékeket egyedi kulcs alapján érhetjük el. 

Dictionary<string, int> jegyek =
    new Dictionary<string, int>();

jegyek.Add("Anna", 5);
jegyek.Add("Béla", 4);

Console.WriteLine(jegyek["Anna"]);

3. HashSet – halmaz

A HashSet egyedi elemeket tárol, ezért ugyanaz az érték csak egyszer szerepelhet benne. 

HashSet<int> szamok = new HashSet<int>();

szamok.Add(10);
szamok.Add(20);
szamok.Add(10);

Console.WriteLine(szamok.Count); // 2

4. Fontos különbségek

  • List: rendezett, indexelhető, ismétlődő elemeket is tárolhat.
  • Dictionary: egyedi kulcsokhoz rendel értékeket.
  • HashSet: csak egyedi elemeket tárol, nincs indexelése.

Lényeg: a List elemek tárolására, a Dictionary kulcs-érték párok kezelésére, a HashSet pedig egyedi értékek tárolására alkalmas.

Öröklődés és származtatás

Ismerd meg, hogyan örökölhetnek az osztályok tulajdonságokat és metódusokat más osztályoktól.

1. Öröklődés

Az öröklődés segítségével egy osztály átveheti egy másik osztály elérhető mezőit és metódusait.

  • Ősosztály: amelyből öröklünk.
  • Leszármazott osztály: amely örököl.
  • : az öröklődést jelöli.
  • base: az ősosztály konstruktorának vagy tagjának elérésére szolgál.

2. Példa öröklődésre

class Alakzat
{
    protected double a;

    public Alakzat(double a)
    {
        this.a = a;
    }
}

class Teglalap : Alakzat
{
    private double b;

    public Teglalap(double a, double b) : base(a)
    {
        this.b = b;
    }

    public double Terulet()
    {
        return a * b;
    }
}

3. Konstruktor meghívása – base

A base(a) meghívja az ősosztály konstruktorát, és átadja neki az a paramétert.

Lényeg: az öröklődés lehetővé teszi a közös tulajdonságok és metódusok újrafelhasználását, így csökkenti a kódismétlést.

Korai és késői kötés

Ismerd meg, mikor dől el, hogy egy objektum melyik metódusát hajtja végre a program.

1. Korai kötés

Korai kötés esetén a meghívandó metódus már fordítási időben meghatározható. Ilyen például a nem virtuális metódusok hívása. 

class Alakzat
{
    public void Kiiras()
    {
        Console.WriteLine("Alakzat");
    }
}

Alakzat a = new Alakzat();
a.Kiiras();

2. Késői kötés

Késői kötés esetén a program futás közben dönti el, hogy az objektum tényleges típusa alapján melyik felüldefiniált metódus fusson le. C#-ban ezt a virtual és override kulcsszavak teszik lehetővé. 

class Alakzat
{
    public virtual void Kiiras()
    {
        Console.WriteLine("Alakzat");
    }
}

class Teglalap : Alakzat
{
    public override void Kiiras()
    {
        Console.WriteLine("Téglalap");
    }
}

Alakzat a = new Teglalap();
a.Kiiras(); // Téglalap

3. Fontos kulcsszavak

  • virtual: lehetővé teszi a metódus felülírását.
  • override: a leszármazott osztályban felülírja a metódust.
  • new: elrejti az ősosztály azonos nevű tagját, nem valódi felülírás.

Lényeg: korai kötésnél a metódus kiválasztása fordítási időben, késői kötésnél futás közben, az objektum tényleges típusa alapján történik.

Absztrakt osztályok és metódusok

Ismerd meg, hogyan határozhatunk meg közös alapot és kötelezően megvalósítandó metódusokat.

1. Absztrakt osztály – abstract

Az absztrakt osztály közös alapot biztosít a leszármazott osztályoknak, de közvetlenül nem példányosítható.

2. Absztrakt metódus

Az absztrakt metódus csak a fejlécét tartalmazza, a törzsét a leszármazott osztálynak kell megvalósítania.

3. Példa

abstract class Alakzat
{
    protected double a;

    public Alakzat(double a)
    {
        this.a = a;
    }

    public abstract double Terulet();
    public abstract double Kerulet();
}

class Teglalap : Alakzat
{
    private double b;

    public Teglalap(double a, double b) : base(a)
    {
        this.b = b;
    }

    public override double Terulet()
    {
        return a * b;
    }

    public override double Kerulet()
    {
        return (a + b) * 2;
    }
}

4. Fontos kulcsszavak

  • abstract: absztrakt osztály vagy metódus jelölése.
  • override: az absztrakt metódus megvalósítása.
  • base: az ősosztály konstruktorának meghívása.

Lényeg: az absztrakt osztály meghatározza a közös felépítést, az absztrakt metódusok pedig előírják, hogy a leszármazott osztályok milyen műveleteket valósítsanak meg.
