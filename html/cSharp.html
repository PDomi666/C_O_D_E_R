C# – Alapvető vezérlési szerkezetek

Elágazás – if, else

Feltétel alapján különböző utasításokat hajt végre.

if (a > b)
{
    Console.WriteLine("A nagyobb");
}
else
{
    Console.WriteLine("B nagyobb vagy egyenlő");
}

Többágú elágazás – switch

Egy változó értéke alapján választ a lehetőségek közül.

switch (nap)
{
    case 1:
        Console.WriteLine("Hétfő");
        break;
    case 2:
        Console.WriteLine("Kedd");
        break;
    default:
        Console.WriteLine("Másik nap");
        break;
}

Ciklusok – for, foreach, while

A for ismert ismétlésszám esetén használható.

for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

A foreach egy kollekció elemein halad végig.

int[] szamok = { 1, 2, 3 };

foreach (int szam in szamok)
{
    Console.WriteLine(szam);
}

A while addig ismétel, amíg a feltétel igaz.

int i = 0;

while (i < 5)
{
    Console.WriteLine(i);
    i++;
}
