SQL-lekérdezések alapjai

Az SQL segítségével adatokat kérdezhetünk le, szűrhetünk, rendezhetünk és kapcsolhatunk össze adatbázistáblákból.

A legfontosabb SQL-utasítások

A lekérdezések különböző részei meghatározzák, hogy honnan származzanak az adatok, milyen feltételeknek feleljenek meg, és hogyan jelenjenek meg.

Utasítás Jelentése
SELECT Kiválasztja a megjelenítendő oszlopokat.
DISTINCT Eltávolítja az ismétlődő eredményeket.
FROM Megadja, melyik táblából kérjük le az adatokat.
INNER JOIN Összekapcsolja a két táblában egymáshoz tartozó rekordokat.
WHERE Feltétel alapján szűri a rekordokat.
GROUP BY Csoportosítja az azonos értékekhez tartozó rekordokat.
HAVING A csoportosítás után szűri a csoportokat.
ORDER BY Növekvő vagy csökkenő sorrendbe rendezi az eredményt.

Példák

-- 1. Adatok lekérdezése
SELECT nev, atlag
FROM Tanulok;

-- 2. Egyedi osztályok megjelenítése
SELECT DISTINCT osztaly
FROM Tanulok;

-- 3. Szűrés
SELECT nev, atlag
FROM Tanulok
WHERE atlag >= 4.00;

-- 4. Rendezés
SELECT nev, atlag
FROM Tanulok
ORDER BY atlag DESC;

-- 5. Csoportosítás
SELECT osztaly, COUNT(*) AS letszam
FROM Tanulok
GROUP BY osztaly;

-- 6. Csoportok szűrése
SELECT osztaly, COUNT(*) AS letszam
FROM Tanulok
GROUP BY osztaly
HAVING COUNT(*) >= 5;

-- 7. Két tábla összekapcsolása
SELECT Tanulok.nev, Osztalyok.osztaly_nev
FROM Tanulok
INNER JOIN Osztalyok
    ON Tanulok.osztaly_id = Osztalyok.id;

Tipp: a WHERE az egyes rekordokat szűri, a HAVING pedig a csoportokat. Az ASC növekvő, a DESC csökkenő rendezést jelent.

SQL-feltételek és szűrések

A feltételek segítségével pontosan meghatározhatjuk, hogy mely rekordokat szeretnénk megjeleníteni.

Feltételek és operátorok

Operátor Mit csinál? Példa
BETWEEN Két határérték közötti értékeket keres, a határokat is beleértve. atlag BETWEEN 3 AND 5
IN Ellenőrzi, hogy az érték szerepel-e egy listában. osztaly IN ('10.A', '10.B')
IS NULL A hiányzó értékeket keresi. atlag IS NULL
IS NOT NULL A nem hiányzó értékeket keresi. atlag IS NOT NULL
NOT Tagadja a feltételt. NOT (atlag < 3)
LIKE Szövegminta alapján keres. nev LIKE 'Kiss%'
AND Minden feltételnek teljesülnie kell. atlag >= 4 AND osztaly = '10.A'
OR Legalább az egyik feltételnek teljesülnie kell. osztaly = '10.A' OR osztaly = '10.B'

Példák

-- 1. Átlag egy megadott tartományban
SELECT nev, atlag
FROM Tanulok
WHERE atlag BETWEEN 3.00 AND 5.00;

-- 2. Több osztály kiválasztása
SELECT nev, osztaly
FROM Tanulok
WHERE osztaly IN ('10.A', '10.B');

-- 3. Hiányzó átlagok
SELECT nev
FROM Tanulok
WHERE atlag IS NULL;

-- 4. Két osztály kizárása
SELECT nev, osztaly
FROM Tanulok
WHERE osztaly NOT IN ('10.A', '10.B');

-- 5. Kiss névvel kezdődő nevek
SELECT nev
FROM Tanulok
WHERE nev LIKE 'Kiss%';

-- 6. Annát tartalmazó nevek
SELECT nev
FROM Tanulok
WHERE nev LIKE '%Anna%';

-- 7. Két feltétel egyszerre
SELECT nev, atlag
FROM Tanulok
WHERE atlag >= 4.00
  AND osztaly = '10.A';

Tipp: a LIKE operátornál a % tetszőleges számú karaktert, az _ pontosan egy karaktert helyettesít. A NULL ellenőrzésére IS NULL vagy IS NOT NULL használatos, nem az = NULL.

SQL-összesítő függvények

Az összesítő függvények segítségével több rekordból egyetlen értéket számíthatunk ki, például létszámot, átlagot vagy szélsőértéket.

A legfontosabb összesítő függvények

Függvény Jelentése Példa
COUNT() Megszámolja a sorokat vagy a nem NULL értékeket. COUNT(*)
SUM() Összeadja a numerikus értékeket. SUM(fizetes)
AVG() Kiszámítja a numerikus értékek átlagát. AVG(atlag)
MIN() Megadja a legkisebb értéket. MIN(atlag)
MAX() Megadja a legnagyobb értéket. MAX(atlag)

Példák

-- 1. Tanulók száma
SELECT COUNT(*) AS letszam
FROM Tanulok;

-- 2. Átlagok összege
SELECT SUM(atlag) AS osszeg
FROM Tanulok;

-- 3. Átlagos tanulmányi eredmény
SELECT AVG(atlag) AS tanulmanyi_atlag
FROM Tanulok;

-- 4. Legkisebb és legnagyobb átlag
SELECT
    MIN(atlag) AS minimum,
    MAX(atlag) AS maximum
FROM Tanulok;

-- 5. Összesítés osztályonként
SELECT
    osztaly,
    COUNT(*) AS letszam,
    AVG(atlag) AS osztalyatlag
FROM Tanulok
GROUP BY osztaly;

-- 6. Csak a legalább 4-es átlagú osztályok
SELECT
    osztaly,
    AVG(atlag) AS osztalyatlag
FROM Tanulok
GROUP BY osztaly
HAVING AVG(atlag) >= 4.00
ORDER BY osztalyatlag DESC;

Tipp: a GROUP BY külön-külön végez összesítést minden csoportra. A HAVING segítségével az összesített eredmények alapján szűrhetünk.

SQL-szövegkezelő függvények

A szövegkezelő függvényekkel karakterláncokat alakíthatunk át, vághatunk ki, fűzhetünk össze vagy tisztíthatunk meg.

Szövegkezelő függvények áttekintése

Függvény Mit csinál? Példa és eredmény
UPPER() Nagybetűssé alakít. UPPER('alma') → ALMA
LOWER() Kisbetűssé alakít. LOWER('ALMA') → alma
LENGTH() Megadja a szöveg hosszát. LENGTH('alma') → 4
CONCAT() Szövegeket fűz össze. CONCAT('Jó', ' nap') → Jó nap
SUBSTRING() Kivág egy szövegrészletet. SUBSTRING('alma', 1, 2) → al
TRIM() Eltávolítja a szélső szóközöket. TRIM(' alma ') → alma
REPLACE() Lecseréli a megadott szövegrészt. REPLACE('alma', 'a', 'o') → olmo
LEFT() A bal oldalról ad vissza karaktereket. LEFT('alma', 2) → al
RIGHT() A jobb oldalról ad vissza karaktereket. RIGHT('alma', 2) → ma

Példák

SELECT UPPER('alma') AS nagybetus;
SELECT LOWER('ALMA') AS kisbetus;
SELECT LENGTH('alma') AS hossz;
SELECT CONCAT('Jó', ' nap') AS koszontes;
SELECT SUBSTRING('alma', 1, 2) AS reszlet;
SELECT TRIM(' alma ') AS tiszta;
SELECT REPLACE('alma', 'a', 'o') AS csere;
SELECT LEFT('alma', 2) AS bal_oldal;
SELECT RIGHT('alma', 2) AS jobb_oldal;

-- Több függvény használata együtt
SELECT UPPER(TRIM(nev)) AS tisztitott_nev
FROM Tanulok;

Tipp: egy függvény eredményét átadhatjuk egy másik függvénynek is. Így például először eltávolíthatjuk a felesleges szóközöket, majd nagybetűssé alakíthatjuk a nevet.

SQL-matematikai és dátumkezelő függvények

A matematikai függvények számításokat végeznek, a dátumkezelő függvények pedig segítenek az időpontok, dátumrészek és dátumkülönbségek meghatározásában.

Matematikai függvények

Függvény Mit csinál? Példa és eredmény
ROUND() Kerekít. ROUND(12.567, 2) → 12.57
CEIL() / CEILING() Felfelé kerekít. CEIL(4.2) → 5
FLOOR() Lefelé kerekít. FLOOR(4.9) → 4
ABS() Abszolút értéket számol. ABS(-10) → 10
POWER() Hatványoz. POWER(2, 3) → 8
SQRT() Négyzetgyököt számol. SQRT(25) → 5
MOD() Megadja az osztási maradékot. MOD(10, 3) → 1

Dátumkezelő függvények

Függvény vagy kifejezés Mit csinál?
CURRENT_DATE Az aktuális dátumot adja vissza.
CURRENT_TIMESTAMP Az aktuális dátumot és időt adja vissza.
EXTRACT() Kinyeri a dátum egy részét, például az évet vagy a hónapot.
DATEDIFF() Kiszámítja két dátum különbségét; a pontos működés adatbázisfüggő.
DATE_ADD() Időt ad hozzá egy dátumhoz MySQL-ben.
YEAR() Kinyeri az évet MySQL-ben.
MONTH() Kinyeri a hónapot MySQL-ben.
DAY() Kinyeri a hónap napját MySQL-ben.

Példák

-- Matematikai műveletek
SELECT ROUND(12.567, 2);
SELECT CEIL(4.2);
SELECT FLOOR(4.9);
SELECT ABS(-10);
SELECT POWER(2, 3);
SELECT SQRT(25);
SELECT MOD(10, 3);

-- Aktuális dátum és idő
SELECT CURRENT_DATE;
SELECT CURRENT_TIMESTAMP;

-- Dátumrészek kinyerése MySQL-ben
SELECT YEAR('2026-10-15');
SELECT MONTH('2026-10-15');
SELECT DAY('2026-10-15');

-- Dátumrészek kinyerése szabványosabb szintaxissal
SELECT EXTRACT(YEAR FROM CURRENT_DATE);
SELECT EXTRACT(MONTH FROM CURRENT_DATE);
SELECT EXTRACT(DAY FROM CURRENT_DATE);

-- Két dátum közötti napok száma MySQL-ben
SELECT DATEDIFF('2026-10-15', '2026-10-01');
-- Eredmény: 14

-- Hét nap hozzáadása egy dátumhoz MySQL-ben
SELECT DATE_ADD('2026-10-15', INTERVAL 7 DAY);
-- Eredmény: 2026-10-22

Tipp: a matematikai függvények többnyire hasonlóan működnek a különböző adatbázisokban, de a dátumfüggvények szintaxisa eltérhet. A YEAR(), MONTH(), DAY(), DATEDIFF() és DATE_ADD() példái MySQL-hez készültek.
