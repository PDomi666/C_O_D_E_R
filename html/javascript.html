Aszinkron programozás és API

Ismerd meg az aszinkron működést, a JSON-adatokat és a szerverkommunikációt.

1. Szinkron és aszinkron működés

  • Szinkron: az utasítások egymás után futnak.
  • Aszinkron: a hosszabb műveletek közben más kód is futhat.

2. Callback és időzítők

  • Callback: később meghívott függvény.
  • setTimeout(): egyszeri késleltetés.
  • setInterval(): ismétlődő végrehajtás.
  • clearInterval(): időzítő leállítása.
  • addEventListener(): események kezelése.
  • Event Loop: az aszinkron feladatok ütemezését segíti.

3. Promise és async/await

A Promise egy későbbi eredményt vagy hibát képvisel. A .then() a sikeres eredményt, a .catch() a hibát kezeli. Az async/await egyszerűbbé teszi az aszinkron kódot, a try/catch pedig a hibakezelést.

4. API, HTTP és JSON

  • API: alkalmazások közötti kommunikáció.
  • GET: adatok lekérése.
  • POST: adatok küldése.
  • PUT / PATCH: adatok módosítása.
  • JSON.stringify(): objektum átalakítása JSON-szöveggé.
  • JSON.parse(): JSON-szöveg feldolgozása.

5. Adatok lekérése fetch() segítségével

A fetch() HTTP-kérést indít. A response.json() feldolgozza a JSON-választ, a response.ok pedig ellenőrzi, sikeres volt-e a kérés.

getFetch() függvény

const getMethodFetch = async (url) => {
    try {
        const response = await fetch(url);
        if (!response.ok) {
            throw new Error(`GET hiba: ${response.status} ${response.statusText}`);
        }
        return await response.json();
    } catch (error) {
        throw new Error(`Hiba történt: ${error.message}`);
    }
};

Használata

const fetchData = async () => {
    try {
        const data = await getMethodFetch (url);
        console.log('Fetch eredménye: ', data);
    } catch (error) {
        console.error('Hiba történt: ', error);
    }
};

Lényeg: a fetch() lekéri az adatokat, az async/await megkönnyíti a feldolgozást, a try/catch és a catch() pedig segít a hibák kezelésében.
